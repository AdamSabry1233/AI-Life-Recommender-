# AI Life Recommender

A multi-agent AI system that recommends a **movie**, **meal**, **book**, and **daily habit** based on how you're feeling.

Built with LangGraph, Matrix Factorization (PyTorch), Groq LLM (Llama 3.1), and FAISS memory.
